## Logical Address and Physical Address (8086)

### Logical Address
The address generated by the CPU is called a logical address.
Format:
```
Logical Address (LA) = Segment : Offset
```
Example:
```
CS:IP = 2000:0100H
```

---

### Physical Address
The actual memory location in RAM is called the physical address.
Formula:
```
Physical Address (PA) = Segment × 10H + Offset
```
Example
Given:
```
CS = 2000H
IP = 0100H
Physical Address = 2000H × 10H + 0100H
                 = 20000H + 0100H
                 = 20100H
```
---

### Difference

| Feature | Logical Address  | Physical Address       |
| ------- | ---------------- | ---------------------- |
| Nature  | Generated by CPU | Actual memory location |
| Format  | Segment:Offset   | Single 20-bit address  |
| Example | 2000:0100        | 20100H                 |
| Used by | Programmer       | Memory hardware        |

---

# In 8086, each segment works with a specific default offset register.
CS uses IP, DS uses BX/SI/DI or direct addressing, SS uses SP/BP, and ES mainly uses DI for string operations.

---
| Segment | Offset Register(s)   | Usage             |
| ------- | ---------------------| ----------------- |
| CS      | IP                   | Instruction fetch |
| DS      | BX, SI, DI, [direct] | Data access       |
| SS      | SP, BP               | Stack operations  |
| ES      | DI                   | String/extra data |
---

### 1. Code Segment (CS)
* Offset register: **IP (Instruction Pointer)**
* Used for instruction fetching

```text
CS : IP
```

---

### 2. Data Segment (DS)
* Offset registers: **BX, SI, DI, direct address**
* Used for data access

```text
DS : BX / SI / DI / [direct]
```

Example:
```asm
MOV AX, [BX]   → DS:BX
```

---

### 3. Stack Segment (SS)
* Offset registers: **SP, BP**
* Used for stack operations

```text
SS : SP / BP
```

Example:
```asm
PUSH AX   → SS:SP
```

---

### 4. Extra Segment (ES)
* Offset register: **DI (mainly)**
* Used in string operations

```text
ES : DI
```

Example:
```asm
MOVSB → uses DS:SI and ES:DI
```
